# اپ مشاور املاک — فاز ۱ (پایه و منطق اصلی)

## این فاز چه چیزی داره؟
✅ ساختار کامل پروژه اندروید (Kotlin + Jetpack Compose + MVVM)
✅ دیتابیس محلی Room با ۴ جدول: `Property`، `Client`، `ContactLog`، `Visit`
✅ Repository لایه برای هر دو موجودیت
✅ **موتور تطبیق خودکار دوطرفه** (`MatchingEngine`) — وقتی ملکی ثبت می‌شود متقاضیان سازگار پیدا می‌شوند و برعکس
✅ تزریق وابستگی با Hilt
✅ صفحات: لیست ملک، ثبت ملک، لیست متقاضی، ثبت متقاضی + ناوبری پایین صفحه
✅ کار کاملاً آفلاین (بدون نیاز به اینترنت)

## چطور بازش کنم؟
1. پروژه رو در **Android Studio (نسخه Koala یا جدیدتر)** باز کن: File → Open → پوشه `realestate_app`
2. صبر کن Gradle Sync تموم بشه (نیاز به اینترنت برای دانلود وابستگی‌ها داره)
3. یک پروژه Firebase بساز و فایل `google-services.json` رو داخل پوشه `app/` بذار (چون `build.gradle` به پلاگین Firebase وابسته‌ست) — یا اگه فعلاً نمی‌خوای Firebase رو فعال کنی، بخش `google-services` plugin و وابستگی‌های Firebase رو موقتاً کامنت کن.
4. Run را روی یک شبیه‌ساز یا گوشی واقعی بزن.

## نقشه راه فازهای بعدی (به ترتیب اولویت)

### فاز ۲ — تکمیل تجربه کاربری اصلی
- صفحه جزئیات ملک با گالری عکس (آپلود از دوربین/گالری با Coil)
- صفحه جزئیات متقاضی + نمایش لیست ملک‌های پیشنهادی (استفاده از `MatchingEngine` که از قبل آماده‌ست)
- دکمه تماس مستقیم و ارسال پیامک از داخل کارت ملک/متقاضی
- ثبت تاریخچه تماس (`ContactLogEntity` از قبل آماده‌ست، فقط UI لازمه)

### فاز ۳ — نقشه
- یکپارچه‌سازی Neshan SDK یا Google Maps Compose
- انتخاب موقعیت روی نقشه هنگام ثبت ملک (فیلد `latitude/longitude` از قبل در دیتابیس هست)
- نمایش خوشه‌ای (cluster) همه ملک‌ها روی یک نقشه کلی

### فاز ۴ — همگام‌سازی ابری و چندکاربره
- فعال‌سازی Firebase Auth برای ورود مشاوران
- Sync دوطرفه Room ↔ Firestore با WorkManager (کار در پس‌زمینه، حتی وقتی آفلاین بودی و بعد آنلاین شدی)
- Security Rules برای محدود کردن دسترسی هر دفتر به داده خودش

### فاز ۵ — یادآوری، تقویم و گزارش‌گیری
- اتصال `VisitEntity` به تقویم سیستم برای یادآوری بازدید
- نوتیفیکیشن پیگیری (`followUpDate` در `ContactLogEntity`)
- خروجی PDF/Excel از لیست ملک‌ها
- داشبورد آماری (تعداد معاملات موفق، درآمد کمیسیون)

## نکته مهم درباره ساخت واقعی APK
این محیط (چت) امکان نصب Android SDK و کامپایل واقعی رو نداره؛ کدها استاندارد و کامل نوشته شدن و باید مستقیم در Android Studio بدون مشکل ساخته بشن. اگه هنگام Sync یا Build با خطایی مواجه شدی (مثلاً به‌خاطر آپدیت نسخه پلاگین‌ها)، همون خطا رو برام بفرست تا اصلاحش کنم.
