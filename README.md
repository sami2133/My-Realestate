# املاک من — اپ مشاور املاک (Android)

نام پکیج: `com.realestate.sami`

اپ مدیریت ملک و متقاضی برای دفتر/تیم مشاوران املاک — کاملاً آفلاین کار می‌کند و به‌صورت اختیاری بین چند نفر روی Google Drive همگام می‌شود.

## معرفی کلی

اپ دو موجودیت اصلی دارد: **ملک** و **متقاضی**. برای هرکدام می‌شود ثبت، جست‌وجو، پیگیری تماس و بازدید انجام داد. نکته‌ی مرکزی اپ **موتور تطبیق خودکار دوطرفه** است: به‌محض ثبت یک ملک جدید، متقاضیان سازگار با آن (بر اساس بودجه، متراژ، نوع معامله، منطقه و...) پیدا می‌شوند و برعکس — با ثبت متقاضی جدید، ملک‌های سازگار موجود نشانش داده می‌شوند.

تمام رابط کاربری فارسی، راست‌به‌چپ، با تاریخ شمسی و فرمت مبلغ به تومان است؛ نسخه‌ی انگلیسی هم به‌صورت کامل و همگام (بدون رشته‌ی جامانده) در کنارش نگهداری می‌شود.

## بخش‌های اصلی اپ (تب‌های پایین صفحه)

- **ملک‌ها** — لیست، ثبت، جزئیات (گالری عکس، وضعیت: قابل معرفی/رزرو/فروخته‌شده/بایگانی، متقاضیان سازگار زنده، تماس/پیامک مستقیم، تاریخچه‌ی پیگیری، بازدیدها)
- **متقاضیان** — همان ساختار، با ملک‌های سازگار زنده به‌جای متقاضی
- **نقشه** — نمایش همه‌ی ملک‌های دارای موقعیت روی نقشه‌ی گوگل؛ هنگام ثبت ملک هم می‌شود موقعیت دقیق را با پین وسط‌نقشه یا دکمه‌ی «موقعیت فعلی من» انتخاب کرد
- **ابزارها/گزارش‌ها** — داشبورد آماری (تعداد ملک، معاملات موفق، متقاضیان فعال، بازدیدهای پیش‌رو، برآورد کمیسیون بر اساس نرخی که خودت وارد می‌کنی)، و خروجی PDF/Excel از لیست ملک‌ها برای اشتراک‌گذاری در واتس‌اپ/ایمیل/تلگرام
- **تیم** — ورود با حساب گوگل و همگام‌سازی داده‌ها با بقیه‌ی اعضای تیم (توضیح کامل پایین‌تر)
- **تنظیمات**

## بازدید، تقویم و یادآوری پیگیری

از صفحه‌ی جزئیات ملک/متقاضی می‌شود یکی از طرف‌های سازگار را برای بازدید انتخاب و تاریخ/ساعت را ثبت کرد؛ یک رویداد آماده هم به تقویم پیش‌فرض گوشی فرستاده می‌شود. نتیجه‌ی هر بازدید (در انتظار/علاقه‌مند/بی‌علاقه/معامله موفق) از همان‌جا ثبت می‌شود.

برای هر یادداشت تماس می‌شود موعد پیگیری بعدی را با چیپ‌های سریع «فردا / ۳ روز دیگر / هفته دیگر» مشخص کرد؛ یک Worker پس‌زمینه هر ۶ ساعت بررسی می‌کند و در صورت فرارسیدن موعد، نوتیفیکیشن محلی نشان می‌دهد.

## همگام‌سازی تیمی

چون Firestore/کنسول Firebase از داخل ایران بدون VPN در دسترس نیست، بک‌اند همگام‌سازی به‌جای Firebase از **Google Drive REST API** استفاده می‌کند — بدون نیاز به سرور یا VPS اختصاصی.

**چطور کار می‌کند:**
- هر عضو تیم از تب «تیم» با حساب گوگل خودش وارد می‌شود
- داده‌ها (ملک‌ها، متقاضیان، تاریخچه‌ی تماس، و عکس‌های ملک) به‌صورت فایل‌های JSON و تصویر داخل یک پوشه‌ی مشترک در Drive ذخیره می‌شوند
- ادغام بر اساس «آخرین ویرایش برنده است» (`updatedAt`) انجام می‌شود؛ حذف رکورد هم بین اعضا به‌درستی همگام می‌شود (soft-delete)
- همگام‌سازی خودکار هر ۳۰ دقیقه (قابل محدود کردن به فقط Wi-Fi از تنظیمات تب «تیم») + دکمه‌ی «همگام‌سازی الان»

**تشکیل یک تیم جدید (اولین نفر):**
1. وارد تب «تیم» شو و با حساب گوگلت وارد شو
2. یک‌بار «همگام‌سازی الان» را بزن — پوشه‌ی تیمی به‌صورت خودکار در Drive خودت ساخته می‌شود
3. با دکمه‌ی «اشتراک‌گذاری لینک پوشه‌ی تیمی» لینک را برای بقیه‌ی اعضا بفرست

**پیوستن به یک تیم موجود (نفرات بعدی):**
1. لینکی که نفر اول فرستاده را از او دریافت کن (یا منتظر بمان تا پوشه با ایمیلت Share شود)
2. با حساب گوگل خودت وارد تب «تیم» شو
3. از دکمه‌ی «انتخاب پوشه از Google Drive» پوشه‌ی تیمی را انتخاب کن (روش توصیه‌شده) — یا شناسه/لینکی که نفر اول فرستاده را در کادر «پیوستن به تیم موجود» بچسبان

هر گروه/دفتر می‌تواند مستقل از بقیه، پوشه‌ی تیمی جداگانه‌ی خودش را بسازد؛ اپ محدودیتی روی تعداد تیم‌های همزمان با حساب‌های مختلف ندارد.

### محدودیت‌های شناخته‌شده‌ی فعلی
- **بازدیدها** (`VisitEntity`) هنوز همگام نمی‌شوند — فقط محلی روی همان گوشی هستند
- نوتیفیکیشن یادآوری پیگیری بین اعضا همگام نمی‌شود
- این real-time نیست؛ تأخیر تا ۳۰ دقیقه (یا دستی با دکمه‌ی Sync) طبیعی است

## راه‌اندازی یک‌بار در Google Cloud Console

برای اینکه هر گروه/حساب گوگلی بتواند وارد شود (نه فقط چند نفر از پیش تعریف‌شده)، باید اسکوپ محدود `drive.file` استفاده شود و OAuth consent screen منتشر (Publish) شده باشد:

1. یک پروژه در [Google Cloud Console](https://console.cloud.google.com) بساز (یا همان پروژه‌ی نقشه را استفاده کن)
2. از APIs & Services → Library، «Google Drive API» و «Google Picker API» را فعال کن
3. از **Google Auth Platform → Data Access**، اسکوپ `https://www.googleapis.com/auth/drive.file` را اضافه کن
4. از **Google Auth Platform → Audience**، Publishing status را روی **In production** ببر (نیاز به تکمیل فرم پایه‌ی برندینگ دارد، ولی چون `drive.file` حساس نیست، نیاز به بررسی امنیتی CASA ندارد)
5. از **Google Auth Platform → Clients → Create Client**:
   - نوع: **Android**
   - Package name: `com.realestate.sami`
   - SHA-1 fingerprint: با `./gradlew signingReport` بگیر (هم نسخه‌ی debug هم release)
6. یک **API Key** جدا برای Google Picker بساز (محدود به «Google Picker API») و **Project number** پروژه را از Dashboard یادداشت کن

سپس در `local.properties` (کنار پروژه، هرگز به گیت اضافه نشود):
```properties
MAPS_API_KEY=...
DRIVE_PICKER_API_KEY=...
DRIVE_APP_ID=...   # همان Project number
```

## نقشه — کلید Google Maps

بدون این کلید، بقیه‌ی اپ عادی کار می‌کند ولی تب نقشه صفحه‌ی خاکستری نشان می‌دهد:
1. در Google Cloud Console، «Maps SDK for Android» را فعال کن
2. یک API Key بساز و در `local.properties` به‌عنوان `MAPS_API_KEY` قرار بده (از `AndroidManifest.xml` به‌صورت خودکار خوانده می‌شود)

## دوزبانه‌سازی

تمام متن‌ها از `strings.xml` می‌آیند (هیچ متنی هاردکد نیست). `values/strings.xml` فارسی (پیش‌فرض) و `values-en/strings.xml` انگلیسی است؛ کلیدهای دو فایل ۱۰۰٪ منطبق‌اند. برای زبان سوم، یک پوشه‌ی `values-<کد زبان>` بساز و همان کلیدها را ترجمه کن.

## چطور بازش کنم؟

1. پروژه را در **Android Studio (Koala یا جدیدتر)** باز کن: File → Open → پوشه‌ی `Realestate`
2. صبر کن Gradle Sync تمام شود (نیاز به اینترنت برای دانلود وابستگی‌ها)
3. کلیدهای بخش‌های بالا را در `local.properties` قرار بده (بدون آن‌ها هم اپ به‌جز نقشه/تیم عادی کار می‌کند)
4. Run را روی شبیه‌ساز یا گوشی واقعی بزن
